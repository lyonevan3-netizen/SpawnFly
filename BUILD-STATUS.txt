SpawnFly 1.0.2 source package

This version changes SpawnFly to automatic region-based flight: players with spawnfly.use are granted flight on entering, joining, or respawning inside WorldGuard region spawn; flight is revoked on leaving. There is no /fly command.

This package contains source code and a GitHub Actions workflow, not a prebuilt JAR. The workflow uses Java 25 with Gradle 9.1.0 because Gradle 8.14.3 does not support running on Java 25. A successful GitHub Actions run is required to produce the JAR. Runtime behavior has not been tested on the target server.
